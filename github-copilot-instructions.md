# Use Copliot on GitHub

1.  Open pull request for recommendation

1.  Select **Conversation**.

    1.  Under **Reviewers**, add `Copliot`.

    1.  Under **Copilot AI left a comment**, review comments.

        1.  If comment is not useful for content, add the `Not helpful.` comment and select **Resolve conversation**.

1.  Select **Files changed**.

    1.  Select **Open Copilot... (Alt+Shift+C)** > **Assistive**.

    1.  Select **Conversation options** > **Personal instructions**

    1.  In the **Your instructions** text box, enter your prompt and select **Save**.

    1.  In the **How can I help you?** text box, enter `Please review the files listed in this pull request for the content quality using personal instructions and create a summary checklist of the review findings.` and select **Send now**.

    1.  Review response, copy-and-paste into review comment.
